# 古建研学首版

开发目录：`工作台/`，基于水墨工作台 f550285 增量扩展。原 `/Users/xiaoxiao/shortfilm-agent/comic-drama` 的代码、运行数据和端口均未修改。本目录下 `开发需求.md` 保留本轮需求。

## 本机启动

在本目录下开两个终端：

```bash
cd 工作台
bash scripts/heritage-backend.sh
```

```bash
cd 工作台
bash scripts/heritage-frontend.sh
```

打开 `http://127.0.0.1:3001/ink`。后端为8012，原水墨工作台仍使用3000/8011。

本机 Python 环境和前端依赖通过 `.venv` / `node_modules` 链接复用既有安装，源码与 `.ink-demo` 数据是独立副本。迁移到其他电脑时，进入backend按pyproject.toml/uv.lock安装依赖，进入frontend运行npm ci。没有复制原项目 `.env` 或 config.yaml；真实模型调用前在新工作台“模型与API”自行配置。

## 制作顺序

1. 首页选择“保国寺·找斗拱”或空白讲解站，先填建筑、构件、年级和研学资料四项；保存时自动补全空白的名称、教学目标与观察任务草稿，不调用模型、不覆盖已有内容。观察指引与问题在第2步统一修改，名称和教学目标位于第2步的“课程设置（可选）”。
2. 在实拍标注页核对观察指引和问题；指引写清往哪里看、找什么，有需要时补充具体观察位置，不再单独填写站位。上传真实定位照片；标注后可点击“从当前标注生成特写”，直接裁出同一画面并继承标注与署名；也可展开“另传实拍特写”手动上传。已知素材上传后自动带入来源、作者和许可；其他照片选择“自己拍摄”或“供图方已授权”即可带入说明，无需手填三项。已有完整署名保留；打开旧项目时自动补齐可识别照片的缺失信息。在原图上拖动矩形或箭头，或输入坐标百分比。自动特写随定位图与原标注关联，无需再标一次；定位图或标注变更后须更新特写，才能确认与导出。完整保留照片为默认，可选择16:9横屏裁切并移动裁切位置。保存后查看与导出一致的横屏预览。
3. 在第2步核对资料、标注与观察指引；另传特写时同时核对为同一目标；自动特写的对应关系由来源和坐标关联校验。点击“确认并进入研学脚本”即可保存并确认，已确认且未修改时可直接继续。替换照片会清空对应标注与确认，并重新识别新照片署名。
4. 研学资料同时承载地方历史、构件特点和资料来源；已有内置案例可点“补入本案例历史”，不覆盖原有文字。使用不调用模型的脚本模板，或点击“AI起草（计费）”。脚本可编辑，老师审核后确认。模型只能依据老师提供的构件资料，不自动认证建筑事实。
5. 在“水墨故事”导入已有已确认镜头（独立复制，不影响来源），或继续使用原水墨角色、场景、分镜和视频功能制作。故事段总长不超过历史引入时长（默认12秒）；短于目标时长在末帧停留补齐，不截对白。
6. 在“导出与试用”输出按设定时长合成的MP4和一页A4 PDF。默认30秒时，单图顺序：历史引入12秒→实物观察11秒→现场任务7秒；双图顺序：历史引入12秒→全景观察6秒→同目标特写5秒→现场任务7秒。两份导出共享当前确认版本。实拍片尾保留标注、观察指引、问题和照片署名。
7. 修改资料、照片或标注后，两份旧文件保留但标记待更新；更新脚本需重新审核。导出失败不会覆盖旧导出，手动重试即可。
8. 真正现场试用后，老师填写参与人数、无额外方向提示找到人数与备课耗时。系统不会代填现场验证通过。

首页及项目切换仅显示古建研学项目。底层仍保留水墨镜头制作与旧素材兼容能力；本副本中的操作不会同步回旧工作台。

## 照片与许可

本机保国寺素材在 `素材/`，照片与视频未上传仓库；来源与署名见素材目录说明。示例标注只用于技术演示，尚不能替代老师对实际构件、外檐时代与观察站位的现场确认。宁远文庙、太和殿模板已内置，真实照片需课程老师另行提供或核对许可。

可选旁白：导出页勾选“为三段台词配音”才会调用在线语音服务，并替换故事原声。系统检查每段台词能否放入12/11/7秒，超长会提示缩短，不截断对白。不勾选则保留已有故事声音，实拍片尾使用字幕。

## 从 GitHub 安装

仓库只包含代码、模板和开发文档，不含密钥、本机数据库、依赖或生成图片/视频。首次运行会创建空白本地数据；请在页面上传照片并创建研学项目。

```bash
cd 工作台/backend
uv sync --extra dev --python 3.12
cd ../frontend
npm ci
```

然后在两个终端分别执行上面的研学启动脚本。生成模型需在“模型与 API”配置自己的账户。导出需要 FFmpeg（可使用 imageio-ffmpeg 自带版本），任务卡需要中文字体；macOS 默认使用宋体，Linux 请安装 Noto CJK 字体。

`scripts/heritage-acceptance.py` 位于 `工作台/` 内，是本机真实素材的技术验收脚本；运行前须自行准备照片与可复用镜头。后端单元测试不要求这些本机数据。

保留原底座 MIT 许可证与署名，见 [LICENSE](工作台/LICENSE)。

## 历史引入的资料与边界

历史段讲一个地方历史重点，再引出本次构件；实物观察段使用构件特点、真实照片与标注。资料缺少历史时，模板保留明确待补充标记，不能直接确认；AI起草会先要求补充资料，不调用模型。现场核对备注和来源链接不会拼进台词。已有脚本与镜头不会因模板更新被自动覆盖。

内置案例历史来源：
- 保国寺：大殿重建于北宋，清代又有修缮；参见[中国港口博物馆](https://www.portmuseum.cn/doc/sx/gbzx/read/38733.shtml)。不把现状照片中的全部木构件一概视为北宋原构。
- 宁远文庙：始建年代与现存清代重建建筑区分说明，参见[湖南省文物局](https://wwj.hunan.gov.cn/wwj/c100310/c100311/202507/t20250718_33744186.html)。
- 太和殿：以明清典礼用途与清康熙重建背景引出观察，参见[故宫博物院](https://www.dpm.org.cn/explore/building/236465.html)。

这些为有来源的案例草稿，实际课程仍由老师结合现场核对。

## 自定义三段时长

第3步可分别设置历史引入、实物观察、现场任务的秒数，总时长自动相加，不提供固定时长预设按钮。每段3–180秒，总时长最多300秒。点击“应用时长”保存；起草或保存脚本时也会应用有效的时长草稿。

已有项目保持默认30秒，无需迁移素材。修改时长保留照片确认、标注、脚本文字与已有媒体，仅要求按新时间核对脚本；旧导出保留并标记待更新。不要通过缩短时长自动截断已有对白：历史镜头超过预算会提示调整，不足则末帧补齐。不会因改时间自动调用视频模型。

实物观察有两张照片时按原6:5比例分配整秒（15秒为全景9秒、特写6秒）；只有定位图时使用完整观察段。配音按当前三段时长分别检查与补齐，成片按总时长校验。独立时长版本避免旧页面、旧脚本确认或生成中的旧结果覆盖新计划。

## 课堂播放画幅

古建研学统一采用16:9宽屏：新设定图、分镜候选、三种视频生成模式、配音字幕、预览及MP4导出使用同一画幅，当前输出为1280×720。实拍段使用横向照片区域与右侧讲解，A4任务卡沿用同一照片变换与标注。

已有图片、视频及历史版本均保留；旧竖屏素材等比留边，不拉伸、不自动裁掉目标。需完整宽屏构图时，由用户重新生成并采用候选；已有旧成片重新导出后才会变成宽屏。视频局部调整沿用输入视频的动作与原声，研学候选在本地统一到宽屏。普通水墨项目继续使用原竖屏流程。画幅修改本身不会触发模型调用。

## 管理历史版本

画面、视频和设定图的历史列表支持删除旧版本；展开“已删除版本”可恢复，恢复后仍需手动采用才替换当前版本。正在使用的版本、待确认图片候选和视频调整底稿不能删除。删除保留原文件及引用，不自动清空磁盘素材。使用状态以独立标签显示，操作按钮集中在卡片底部。

## 上传研学资料

第1步“研学资料”右侧点击“上传资料”，支持Word（.docx）、文字版PDF和TXT，单文件最多10MB，PDF最多100页。Word提取正文、表格与文档注释；TXT支持UTF-8、带BOM的UTF-16和GB18030。提取在本地后端完成，不调用模型或OCR。

上传后先查看并编辑提取预览，再选择“追加到资料”或“替换原资料”，核对后保存草稿。提取本身不会修改已保存资料、审核状态或已有素材。资料上限为2万字，超限不会自动截断。扫描PDF、加密或损坏文件会给出具体提示；含无文字页的PDF会提示核对。原上传文件不在服务端归档，项目保存的是用户核对后的文字及文件名来源。
