# Comic Drama

A standalone comic-drama application with the complete six-stage workflow. Only the `comic_drama` scenario is bundled. No API keys, sessions, or generated media are included.

See [README.md](README.md) for setup and configuration. Run `bash scripts/install.sh`, configure your model provider keys, then run `bash scripts/dev.sh`.

This directory is self-contained and can be moved independently. Original MIT license retained in `LICENSE`.
