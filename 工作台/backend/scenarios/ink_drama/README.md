# 水墨创作：本地工作台

入口：`http://127.0.0.1:3000/ink`。复用现有 Next.js、FastAPI 和模型客户端。不是命令行教学骨架。

## 当前模式：试用功能暂不启用

默认直接进入本地创作，无需邀请码或登录。试用次数额度、试用结束、7天到期限制和清理均不生效；已有项目与素材保留。网页隐藏试用反馈及试用管理入口，本机工作区中的项目可直接编辑。

保存、浏览不会调用模型；点击生成按钮会使用当前配置的模型服务并产生相应费用，不再受此前0次试用额度拦截。业务失败仍不自动重试，调用记录保留便于排查。

`SFA_INK_TRIAL_MODE` 默认关闭；以后需要试用时显式设为 `1`，再配置邀请、额度与保留规则。当前默认仍仅供本机使用，不自动开放公网。

## 已接入的操作

网页按五步展示：写故事 → 定人物画风 → 分镜图 → 视频配音 → 预览导出。每次只展示当前步骤和镜头，底部提供主操作；复杂调整放入弹窗。步骤位置按项目保存在浏览器，返回时结合真实产物状态恢复；前置内容修改后回到需要更新的步骤。

用户点击生成参考图后，后端依次出图、识别人物画风；识别失败保留已生成图片，可单独继续准备。上传参考图后同样自动识别。多角色先逐一补齐参考设定，再开始批量意义上的逐镜制作。确认仍由用户主动点击，失败不自动重试。普通分镜生成不重复识别。视频与配音字幕逐镜完成后，可选择已授权配乐或无背景音乐，再合成下载。

在新目录 `.ink-demo/` 下保存 SQLite 状态和私有素材，不使用公开的 `/code` 挂载。重启将运行中任务标为中断，用户核查服务商任务后手动重试。

## 本机启动

启动水墨后端：在项目根目录运行 `bash scripts/ink-backend.sh`（默认8011），前端在 frontend 运行 `npm run dev`（3000）。水墨专用转发使用 `INK_BACKEND_API_URL`，默认 `http://127.0.0.1:8011`，原漫剧转发不变，避免与占用8000的其他项目冲突。当前默认本机创作模式直接进入工作台，无需邀请码，也不应用试用额度。

在水墨页面右上角点击“模型与 API”，选择各步骤模型并填写对应服务商密钥。设置经专用 `/api/ink/settings` 写入该 comic-drama 后端的本地 `backend/config.yaml`，保存后立即生效，不调用模型；已有密钥不回传，留空保留。所有本机水墨项目共用配置，生成过程中不能保存。由启动环境指定的字段在页面只读。当前仅本地创作模式可用，受邀用户不能修改服务配置。请勿将密钥发到聊天或提交 Git。不能复制工坊的 `.env`，也不通过其他应用的通用设置路由。没有增加新的服务商 SDK。

## 后续恢复试用：额度和邀请（当前不生效）

只有显式设置 `SFA_INK_TRIAL_MODE=1` 后，本节机制才生效。

服务端环境变量 `SFA_INK_LOCAL_LIMITS` 可设置本机调用次数额度，例如 JSON 对象 `{"text":1,"vl":4,"image":4,"video":4,"speech":8}`。这些数字是格式示例，不是已获授权的预算；由负责人确定后填写。失败或结果未知的请求也计入次数，避免无限重试。此为次数保护，不是人民币硬上限；服务商 SDK内部行为及价格应另行核对。

外部试用需配置 `SFA_INK_PUBLIC=1`、`SFA_INK_ORIGIN=https://你的试用域名` 和 `SFA_INK_INVITES`。邀请格式是 JSON 数组，每项含 `user`（唯一用户名）、`token`（随机私密邀请码）、`limits`（text/vl/image/video/speech各类次数）。不要提交真实邀请码，至少使用足够长的随机值并通过私密渠道交付用户。Cookie为HttpOnly，HTTPS部署时Secure。不要将邀请码嵌入URL。

公开模式会阻止非水墨的旧 `/api`、`/code`、文档和设置接口，避免绕过个人额度调用旧接口。原项目仍应只在受控网络内运行；反向代理只开放水墨页面/API及所需前端静态资源，不把原开发服务器直接公开。实际公网部署不在本次自动执行范围。

## 配乐库

`music/manifest.json` 初始为空，系统不会伪造授权曲目或自动下载音乐。负责人将已获授权的音频放在同目录，登记数组条目：`{"id":"track1","title":"曲目名","file":"track1.mp3","license":"授权依据和使用范围"}`。网页只展示有文件且有授权登记的条目。曲目选择后复制到项目，以免源库变化破坏作品。

未准备配乐时，可以选择“无背景音乐”合成，保留片段中的配音；选择背景音乐时仍只允许已登记授权的曲目。

## 后续恢复试用：素材保留（当前不生效）

用户主动点击“结束我的试用”并确认后开始7天保留期；期间只读与下载，到期接口拒绝访问。这个触发方式是当前可修改的实现默认，尚需产品负责人确认。

试用开关关闭时清理CLI直接返回，不访问或删除数据。恢复试用后，宿主定时执行清理CLI：`uv run python -m scenarios.ink_drama.cleanup` 默认只预览到期项目；加 `--apply` 才删除本模块到期素材。副本独立复制文件，因此源项目到期不会使副本文件失效。日志不包含密钥；调用账保留最少次数元数据，不含剧本内容。

## 验证边界

自动测试用固定响应验证JSON、设定不自动改写、单镜头失效、访问权限、复制、额度、音频总长和恢复；这些测试不证明实际水墨效果或模型兼容性。真实模型还需在负责人确认额度后做小样，配乐还需授权素材，公网还需部署配置。

视觉返工与音频字幕反馈分开，逐项目保存；5人至少3位认为明显减少并给出具体工作，作为首轮观察标准。


## 分镜候选确认

分镜调整支持“修改细节”（当前图编辑）和“重新设计画面”（不传整张参考图，以已确认人物文字设定和画风重绘）。后一种方式需要用户核对人物一致性。预览接口保存草稿和单个候选，不更新现用图片、镜头内容及视频状态；采用时一起更新图片和描述，并标记下游结果待更新。候选与原图/镜头修订/基线版本绑定，过期候选拒绝采用。支持放弃候选及撤回最近一次采用；撤回保留媒体但下游仍需更新。生成失败保留原图和草稿，不自动重试。刷新可恢复候选与草稿，未提交输入仍属于临时表单。


## 六步创作与独立设定

当前界面按剧本→创作设定→分镜→画面→视频→成片执行。创作设定包含角色、场景、关键道具与统一画风：可手填或调用文本模型提取草稿；可独立生成或上传设定图，人工确认后才用于镜头。分镜引用character_ids、scene_id、prop_ids，确认有效引用后进入画面制作。重绘仅传当前镜头使用的独立设定图（最多6张），不传原分镜整图；无设定图时使用文字约束。

修改设定只标记引用该项的镜头待确认，统一画风变化影响所有镜头。重复确认不改版本。旧项目首次补齐设定时保留媒体，不自动判断旧结果失效；用户须核对原画面与新设定。旧流程浏览器位置使用不同版本key，避免错位跳转。不自动进行模型调用；提取/设定图生成均由按钮触发。
