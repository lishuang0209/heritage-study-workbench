# 宋代山寺场景候选

原创宋代背景美术，非保国寺复原。未修改平台。

参考：宁波中国港口博物馆《保国寺北宋大殿价值解读》讲座介绍，说明北宋大殿与《营造法式》做法的关联：https://www.portmuseum.cn/doc/jy/gbjt/read/38762.shtml

检查：深檐、木柱、柱头铺作和宽阔檐前平台表现明确。斗拱被模型概括为层叠形状，不能据此认为榫卯与铺作结构准确；屋顶与门窗细部仍需建筑资料核对。画面转为佛殿檐前空间，与此前寺门场景有所不同；用于候选评审，暂不替换既有分镜。画面无人，供后续人物合成使用。

## 完整提示词

为原创二维手绘动画短片《山寺借伞》全新生成一张16:9横版场景设定图，无人物。时代美术方向明确为中国宋代江南山间佛寺，以北宋保国寺大殿的早期木构语言为结构灵感，但设计一座虚构的小寺，不复制整个现存寺院群，不将后世增建混入。主建筑是左侧中景一座三开间、单檐歇山顶的小型木构佛殿，宽缓灰瓦屋面、深远出檐、克制的起翘、屋脊简朴，檐下粗壮而清楚的柱头斗拱承托屋顶，柱梁构造连续可信，深褐木柱有轻微收分立于朴素石础上；浅赭灰抹灰墙与木质板门，中央门半开，露出昏暖的室内光。外观是有人日常维护的宋代寺院，不是经历千年后破败的遗址。不要石拱门、清代密集小斗拱、繁复彩绘、龙凤镂雕、大红灯笼、宫殿金瓦、夸张飞翘屋角、日式鸟居、枯山水或现代设施。前檐下有足够两人站立躲雨的宽阔干燥平台，平台与缓缓下行的湿润石阶连接，建筑全貌完整且尺度自然。前景左上深色松枝框景，左下湿石和青苔；中景建筑和平台；右侧三分之一保留青灰群山、山谷雾带、淡树影，三层空气透视，细雨从檐前落下。平视略低的电影全景，画面安静克制，雨天青灰冷光与室内微弱暖赭光相对，湿地反光柔和。
视觉风格：传统水墨意境与朴拙二维动画背景结合，简化大形体，枯笔岩石、淡墨远山、手绘木构轮廓、克制纸面肌理，减少瓦片和石头碎细节，让背景适合搭配简洁平涂动画人物。避免照片写实、3D游戏渲染、精密建筑效果图、过度锐化。暖灰木头、冷青灰山雾、少量苔绿，构图疏朗。不写任何文字或匾额，不要水印。
